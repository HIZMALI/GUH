                                                               HFCT           30mm

                                                               Techimp   HFCT is an inductive sensor for
                                                               partial discharge measurements.
                                                               It is suitable for on/off line PD tests on many
                                                               electrical systems (cables, transformers,
                                                               rotating machine, etc..). It has to be applied
                                                               to the ground connection of the system to
                                                               be tested.

                                                               A BNC termination is available to connect the
                                                               HFCT to the Techimp     PD detection /analyzer
                                                               unit  through a coaxial cable. The arrow
                                                               indicates the output voltage (Vout) direction in
                                                               comparison with the input current (Iin)
                                                               direction: when the sensor is installed with the
                                                               arrow directed to ground junction, the
                                                               detected voltage signal (Vout) has the same
                                                               phase as the input current (Iin).
