# GridSentinel saha konsepti

Üretim sertifikalı cihaz değildir; fiziksel kurulum yapılmadı. Sistem blokları [sistem belgesinde](../../docs/hardware/system-block-diagram.md), kaynak geometriyi izleyen vektör [panel-placement.svg](panel-placement.svg) içinde. Gateway konektör/güç konsepti [arayüz belgesinde](../schematic/interfaces.md), malzeme kategorileri [BOM'da](../bom/indicative-bom.csv).

MPR ve TVOC sürücüleri gerçek belge adreslerini çözer; demo sensör vektörleri sentetiktir. HFCT analog sinyali doğrudan sıradan MCU ADC girişine bağlanmaz. Geniş bant acquisition ve türetilmiş feature katmanı ayrı teknik iş paketidir.
